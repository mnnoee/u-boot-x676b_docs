# MT6789 MSDC1 (SD-карта) — дерево клоков

**Дата:** 2026-08-06  
**Источник:** `src_linux/linux/drivers/clk/mediatek/clk-mt6789-topckgen.c`, `clk-mt6789-apmixed.c`

## Архитектура клоков MSDC1

```
clk26m (26 MHz, внешний кварц)
  └─> tck_26m_mx9_ck (fixed factor 1:1)
        └─> msdc30_1_sel (mux, выбор 1 из 5 источников)
              └─> msdc30_1_ck (fixed factor 1:1) → MSDC1 controller

msdcpll (PLL, регистр 0x350 в apmixedsys)
  ├─> msdcpll_ck (factor 1:1)
  └─> msdcpll_d2 (factor 1:2) → может быть источником для msdc30_1_sel

mainpll → mainpll_d6_d2, mainpll_d7_d2
univpll → univpll_d6_d2
```

## msdc30_1_sel — мультиплексор источников (индекс 0-4)

**Родительские клоки** (`msdc30_1_parents[]`, строка 323):

| Индекс | Имя | Источник | Частота (типичная) |
|--------|-----|----------|-------------------|
| 0 | `tck_26m_mx9_ck` | clk26m | **26 MHz** |
| 1 | `univpll_d6_d2` | univpll / 6 / 2 | ~167 MHz (если univpll=2000MHz) |
| 2 | `mainpll_d6_d2` | mainpll / 6 / 2 | ~137.5 MHz (если mainpll=1650MHz) |
| 3 | `mainpll_d7_d2` | mainpll / 7 / 2 | ~117.8 MHz |
| 4 | `msdcpll_d2` | msdcpll / 2 | ? MHz (зависит от MSDCPLL) |

**Регистр мультиплексора** (строка 690):
- **BASE**: `CLK_CFG_7` (topckgen)
- **SET**: offset `0x80`
- **CLR**: offset `0x84`
- **UPD**: offset `0x88`
- **Биты**: `[10:8]` (3 бита выбора)
- **Gate bit**: бит 15 (в том же регистре)
- **Update bit**: бит 29 (в регистре `0x04 + 0x88 = 0x8C` или `UPD1`)

## MSDCPLL (PLL для MSDC)

**Регистры** (`clk-mt6789-apmixed.c`, строки 65-67):
- **CON0**: `0x350` (в apmixedsys `0x1000C000`)
- **CON1**: `0x354`
- **CON2**: `0x35C` (enable)
- **CON3**: `0x360` (tuner)
- **Enable bit**: бит 0 в CON2
- **Frequency hopping**: `FH_MSDCPLL`, регистр `0x0118` (строка 142)

**Формула частоты PLL (типичная для MTK):**
```
f_out = f_in * (PCW / 2^22) / POSDIV
```
Где:
- `f_in` = 26 MHz
- `PCW` = биты [21:0] в CON1 (`0x354`)
- `POSDIV` = биты [26:24] в CON0 (`0x350`)

## msdc5hclk_sel — шина HCLK (для MSDC0/MSDC1)

**Родительские клоки** (строка 308):

| Индекс | Имя | Источник | Частота |
|--------|-----|----------|---------|
| 0 | `tck_26m_mx9_ck` | clk26m | 26 MHz |
| 1 | `mainpll_d4_d2` | mainpll / 4 / 2 | ~206 MHz |
| 2 | `mainpll_d6_d2` | mainpll / 6 / 2 | ~137.5 MHz |

**Регистр мультиплексора** (строка 685):
- **SET**: `0x70`
- **CLR**: `0x74`
- **UPD**: `0x78`
- **Биты**: `[25:24]` (2 бита)
- **Gate bit**: бит 31
- **Update bit**: бит 27 в `UPD0` (`0x04`)

## Таблица конфигурации из LK

**Из `lk_lk.bin` offset `0xa0a5c` (MSDC1, 20 байт):**

```
01 00 00 03  03 03 00 00  04 00 00 00  00 00 00 00  80 03 00 00
```

**Интерпретация (предположительная):**
- `+0x00`: `0x03000001` — возможно, индекс мультиплексора (3?) + флаги
- `+0x04`: `0x00000303` — делители или режим
- `+0x08`: `0x00000004` — режим (4 бита на что-то)
- `+0x0C`: `0x00000000` — padding
- `+0x10`: `0x00000380` — возможно, индекс HCLK (3) + флаги (0x80)

**Гипотеза 1:** `0x03` в первом поле → выбран `mainpll_d7_d2` (~117.8 MHz)  
**Гипотеза 2:** `0x03` во втором байте → настройка делителя контроллера

## Проверка через U-Boot

### 1. Читаем регистры topckgen (база `0x10000000`)

```bash
md.l 0x10000080 4   # CLK_CFG_7 (содержит msdc30_1_sel)
# биты [10:8] = текущий индекс родителя
# бит 15 = gate (0=enabled)
```

**Ожидаемое значение (если выбран индекс 0, 26MHz):**
```
0x10000080: 0x00000000  # [10:8]=0 (tck_26m), gate=0
```

**Если выбран индекс 3 (mainpll_d7_d2):**
```
0x10000080: 0x00000300  # [10:8]=3
```

### 2. Читаем MSDCPLL

```bash
md.l 0x1000C350 8   # MSDCPLL CON0-CON3
# CON0 [26:24] = POSDIV
# CON1 [21:0] = PCW
# CON2 bit 0 = EN
```

### 3. Проверяем MSDC1 HCLK

```bash
md.l 0x11240000 0x10  # регистры MSDC1
# нужно найти регистр, который показывает частоту source clock
```

### 4. Изменить source clock (ОПАСНО, только для эксперимента)

```bash
# Выбрать индекс 0 (26 MHz) для msdc30_1_sel
mw.l 0x10000084 0x00000700  # CLR: сбросить биты [10:8]
mw.l 0x10000080 0x00000000  # SET: установить [10:8]=0

# Выбрать индекс 3 (mainpll_d7_d2, ~118 MHz)
mw.l 0x10000084 0x00000700  # CLR
mw.l 0x10000080 0x00000300  # SET: [10:8]=3

# Обновить регистр (strobe)
mw.l 0x1000008C 0x20000000  # update bit 29
```

⚠️ **После изменения клока нужно пере-инициализировать MSDC1 контроллер!**

## Сравнение с U-Boot (drivers/mmc/mtk-sd.c)

Текущий драйвер U-Boot использует `SCLK=100 kHz` для инициализации.  
Формула деления (из LK, строка 26768):
```c
FUN_ffff000050f207f0(param_9, 0, 100000);  // mode=0, freq=100kHz
```

**Вопрос:** если source clock = 26 MHz, то делитель = 26000000/100000 = 260.  
Если source clock = 118 MHz, делитель = 1180.

**Проверка делителя в U-Boot:**
```bash
setenv stdout serial  # отключить вывод на дисплей
mmc dev 1             # инициализация MSDC1
md.l 0x11240004 1     # регистр MSDC_IOCON (содержит делитель?)
```

## Диагностика проблемы «карта не отвечает на CMD0»

### Возможные причины:

1. **Неправильный source clock**
   - Если LK настроил `mainpll_d7_d2` (118 MHz), а U-Boot ожидает 26 MHz
   - Или наоборот: U-Boot программирует делитель для 26 MHz, но клок = 118 MHz
   - **Решение:** явно установить source clock в драйвере U-Boot

2. **Отсутствует питание (VMCH/VMC)**
   - PMIC не подал 3.3V на слот SD
   - **Решение:** найти регистры PMIC LDO в BL2 или добавить включение в U-Boot

3. **Неправильная настройка пинов**
   - Pull-up/down, drive strength, slew rate
   - **Решение:** сверить с LK (`FUN_ffff000050f43ae0`, `0x11D40090`)

4. **Не отключён режим boot**
   - MSDC1 застрял в boot mode (бит 4 регистра `+0x78`)
   - **Решение:** добавить очистку перед инициализацией

## Следующие шаги

1. **Дамп регистров топологии клоков через U-Boot shell:**
   ```bash
   md.l 0x10000070 4  # CLK_CFG_6 (msdc5hclk_sel)
   md.l 0x10000080 4  # CLK_CFG_7 (msdc30_1_sel)
   md.l 0x1000C350 8  # MSDCPLL
   ```

2. **Проверить, что LK оставил включённым:**
   ```bash
   md.l 0x10000004 4  # CLK_CFG_UPDATE (биты update)
   ```

3. **Найти в BL2 включение PMIC LDO для SD:**
   - Грепнуть `bl2_ext_disasm.txt` по `0x10026880` (PWRAP CMD)
   - Искать записи с адресами `0x16*`, `0x19*` (типичные LDO регистры MT6358)

4. **Добавить в U-Boot драйвер явную настройку source clock:**
   ```c
   // В mtk-sd.c, перед msdc_init():
   // Выбрать tck_26m_mx9_ck (индекс 0)
   writel(0x00000700, 0x10000084);  // CLR bits [10:8]
   writel(0x00000000, 0x10000080);  // SET bits [10:8] = 0
   writel(0x20000000, 0x1000008C);  // UPDATE bit 29
   udelay(10);
   ```
